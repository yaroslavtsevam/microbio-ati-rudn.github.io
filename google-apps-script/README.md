# Настройка синхронизации тестирования с Google Drive / Google Sheets
«Пищевая микробиология, санитария и гигиена» • Аграрно-технологический институт (АТИ) РУДН

Для автоматической фиксации результатов экспресс-тестирования студентов (Семинар 0: 12 расчетных задач по базовой химии; Семинар 1: 4 расчетные задачи по гомеостазу) в Google Таблицу на вашем Google Диске используется встроенный шлюз **Google Apps Script**.

---

## Пошаговая инструкция по настройке (занимает 2 минуты):

### 1. Создание ведомости на Google Диске
1. Перейдите в [Google Таблицы](https://sheets.google.com) под вашим Google-аккаунтом.
2. Создайте новую таблицу и назовите её:  
   **«Ведомость: Микробиология и базовая химия (АТИ РУДН)»**.

### 2. Подключение скрипта
1. В меню созданной таблицы откройте:  
   **Расширения (Extensions)** $\rightarrow$ **Apps Script**.
2. Удалите стандартный шаблонный код и полностью вставьте содержимое файла **[`Code.gs`](file:///Users/godfreyspencer/Yandex.Disk.localized/Jobs/RUDN/Course_Microbiology/microbio-ati-rudn.github.io/google-apps-script/Code.gs)**.
3. Нажмите кнопку **«Сохранить»** (`Ctrl+S` / `Cmd+S`).

### 3. Развертывание в виде веб-приложения (Web App)
1. В правом верхнем углу нажмите синюю кнопку **«Начать развертывание» (Deploy)** $\rightarrow$ **«Новое развертывание» (New deployment)**.
2. Нажмите на значок шестеренки слева и выберите тип: **«Веб-приложение» (Web app)**.
3. Заполните параметры развертывания:
   - **Описание:** `Синхронизация результатов тестов РУДН (Семинар 0 и Семинар 1)`
   - **Запуск от имени (Execute as):** `Я (ваш Google аккаунт)`
   - **У кого есть доступ (Who has access):** `Все (Anyone)` *(обязательно, чтобы студенты могли отправлять ответы без запроса прав)*.
4. Нажмите **«Развернуть» (Deploy)**.
5. При первом запуске Google запросит подтверждение доступа к вашей таблице:
   - Нажмите *«Предоставить доступ» (Authorize access)*;
   - Выберите свой Google аккаунт;
   - Нажмите *«Дополнительно» (Advanced)* $\rightarrow$ *«Перейти к проекту (небезопасно)»*;
   - Нажмите *«Разрешить» (Allow)*.
6. Скопируйте полученный **URL веб-приложения** (вида `https://script.google.com/macros/s/.../exec`).

### 4. Подключение вашего URL в веб-приложение
1. Откройте файл [`js/config.js`](file:///Users/godfreyspencer/Yandex.Disk.localized/Jobs/RUDN/Course_Microbiology/microbio-ati-rudn.github.io/js/config.js) в репозитории сайта.
2. Замените значение `GOOGLE_SCRIPT_URL` на скопированный URL:
   ```javascript
   const CONFIG = {
     GOOGLE_SCRIPT_URL: 'https://script.google.com/macros/s/ВАШ_ПОЛУЧЕННЫЙ_ID/exec',
     TEST_DURATION_MINUTES: 30,
     TOTAL_TASKS: 12
   };
   ```
3. Сохраните файл, выполните `git commit` и `git push`.

## Как организованы листы в вашей Google Таблице

Скрипт автоматически создает и форматирует раздельные листы для каждого типа тестирования:

### 1. Лист `Ведомость_Семинар_0` (Базовая химия):
- **12 расчетных задач** (по 2 задачи из каждого из 6 разделов базовой химии: концентрации, разведения, кинетика, равновесие, диссоциация, гидролиз/буферы).
- Колонки:
  1. **Квитанция сдачи (Receipt Token)** (например, `RUDN-CHEM-MU0KSLNR-U1RY`)
  2. **Дата и время (МСК)**
  3. **ФИО, Группа, Специальность**
  4. **Итоговый балл** (например, `92 из 100`) и **Верных ответов** (например, `11 из 12`)
  5. **Затраченное время и режим сдачи**
  6. **Блоки по каждой из 12 задач** (Раздел и ID, текст вопроса, исходный ответ студента с единицами измерения, эталон преподавателя, начисленные баллы и вердикт).
  7. **Примечания и ход решения студента**.

### 2. Лист `Ведомость_Семинар_1` (Гомеостаз микроорганизмов):
- **4 расчетные задачи** по микробиологическому гомеостазу (автопротолиз, кислотность, осмотическое давление, диффузия).

## Резервное хранение (LocalStorage)

Если у студента временно пропадет интернет-соединение или возникнет сетевая задержка, все данные моментально сохраняются в локальном хранилище браузера (`localStorage`), а студенту выдается электронная квитанция с уникальным криптографическим проверочным хешем, которую преподаватель всегда может проверить.
