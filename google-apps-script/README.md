# Настройка синхронизации с Google Drive / Google Sheets

Для автоматической записи результатов 15-минутного тестирования студентов в Google Таблицу на вашем Google Диске используется встроенный сервис **Google Apps Script**.

---

## Пошаговая инструкция (занимает 2 минуты):

### 1. Создание ведомости
1. Откройте [Google Таблицы](https://sheets.google.com) на вашем Google Диске.
2. Создайте новую таблицу с названием, например:  
   **«Ведомость: Пищевая микробиология (АТИ РУДН)»**.

### 2. Подключение скрипта
1. В меню созданной таблицы выберите:  
   **Расширения (Extensions)** $\rightarrow$ **Apps Script**.
2. В открывшемся редакторе удалите стандартный код и вставьте содержимое файла **[`Code.gs`](file:///Users/godfreyspencer/Yandex.Disk.localized/Jobs/RUDN/Course_Microbiology/microbio-ati-rudn.github.io/google-apps-script/Code.gs)**.
3. Нажмите кнопку **«Сохранить»** (значок дискеты или `Ctrl+S` / `Cmd+S`).

### 3. Развертывание в виде веб-приложения (Web App)
1. В правом верхнем углу нажмите синюю кнопку **«Начать развертывание» (Deploy)** $\rightarrow$ **«Новое развертывание» (New deployment)**.
2. Нажмите на значок шестеренки слева и выберите тип: **«Веб-приложение» (Web app)**.
3. Заполните параметры развертывания:
   - **Описание:** `Синхронизация результатов тестов РУДН`
   - **Запуск от имени (Execute as):** `Я (ваш Google аккаунт)`
   - **У кого есть доступ (Who has access):** `Все (Anyone)` *(это необходимо, чтобы студенты могли отправлять форму без авторизации под вашим аккаунтом)*.
4. Нажмите **«Развернуть» (Deploy)**.
5. При первом запуске Google запросит стандартное подтверждение прав доступа к таблице: нажмите *«Предоставить доступ»* $\rightarrow$ *«Дополнительно»* $\rightarrow$ *«Перейти к проекту (небезопасно)»* $\rightarrow$ *«Разрешить»*.
6. Скопируйте полученный **URL веб-приложения** (вида `https://script.google.com/macros/s/.../exec`).

### 4. Вставка URL в веб-приложение
1. Откройте файл `js/config.js` в репозитории сайта.
2. Вставьте скопированный URL в параметр `GOOGLE_SCRIPT_URL`:
   ```javascript
   const CONFIG = {
     GOOGLE_SCRIPT_URL: 'https://script.google.com/macros/s/ВАШ_СКРИПТ_ID/exec',
     TEST_DURATION_MINUTES: 15,
     TOTAL_TASKS: 4
   };
   ```
3. Сделайте `git commit` и `git push`.

Готово! Теперь все отправки студентов автоматически фиксируются в реальном времени отдельными строками в вашей Google Таблице с автоматическим расчетом баллов и времени сдачи.
