# Правила для AI-агентов • Курс «Пищевая микробиология» (АТИ РУДН)

Данный документ содержит обязательные правила оформления интерфейса и структуры страниц, которым обязаны следовать все AI-агенты, ассистенты и разработчики при внесении изменений в проект.

---

## 1. Защита хедера главной страницы (Hero Banner Guardrail)

- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО** добавлять любые кнопки (`<button>`, `.cds--btn`), ссылки быстрого перехода, плашки, пилюли или чипсы внутрь блока `.hero-banner` на главной странице (`view-catalog.html`).
- Блок `.hero-banner` предназначен исключительно для редакционной информации:
  1. Надзаголовок (`.hero-banner__pretitle`)
  2. Заголовок первого уровня (`.hero-banner__title`)
  3. Вводный текст / лид (`.hero-banner__lead`)
  4. Блок метрик курса (`.hero-banner__stats`)
- Вся навигация по семинарам, лекциям и контрольным материалам на главной странице должна осуществляться **исключительно через интерактивные карточки каталога** в сетке `.cds--grid` ниже.

---

## 2. Минимализм верхнего меню (Header UI Shell)

- Верхняя навигационная панель (`.cds--header`) должна оставаться строгой и лаконичной в соответствии с корпоративным стилем IBM Carbon Design System.
- В шапке разрешено находиться **только 4 элементам**:
  1. **Бренд / Название курса:** `РУДН • АТИ Пищевая микробиология` (строго без бейджей вида `Dry Lab`).
  2. **Единое выпадающее меню «Ресурсы»** (`data-submenu-trigger="resources"`): содержит прямые текстовые ссылки на каталог, лекцию, семинары, коллоквиум и домашнее задание.
  3. **Переключатель цветовой темы** (`#btn-theme-toggle`).
  4. **Ссылка на репозиторий GitHub** в глобальной области действий (`.cds--header__global`).
- **КАТЕГОРИЧЕСКИ ЗАПРЕЩЕНО**:
  - Создавать отдельные дополнительные пункты меню верхнего уровня в панели навигации.
  - Добавлять цветные бейджи (`.cds--tag`), временные метки («30 мин»), счетчики вопросов («60 вопросов») в ссылки шапки и выпадающего меню. Меню должно быть чистым.

---

## 3. Стандарты типографики IBM Carbon Design System

- Все текстовые блоки, заголовки, параграфы и списки должны оформляться в строгом соответствии с гайдом [IBM Carbon Design System Typography](https://www.carbondesignsystem.com/building-blocks/foundations/typography/):
  - **Гарнитуры:** `IBM Plex Sans` (основной текст и заголовки), `IBM Plex Mono` (код, формулы, химические константы).
  - **Вертикальный ритм:** отступы задаются строго по Carbon 2x Grid (токены `$spacing-03` = 8px, `$spacing-04` = 12px, `$spacing-05` = 16px / 1rem, `$spacing-06` = 24px / 1.5rem, `$spacing-07` = 32px / 2rem).
  - **Межстрочный интервал (line-height):** для чтения теории и методических материалов — `1.5–1.6`.
  - **Ширина строки (Measure):** длинные текстовые блоки теории и кейсов должны ограничиваться шириной ~50–75 символов (`max-width: 52rem–56rem`), предотвращая растягивание строк на сверхшироких экранах.
  - **Никаких разрозненных инлайн-стилей:** типографика регулируется централизованно через стили в `css/main.css`.
