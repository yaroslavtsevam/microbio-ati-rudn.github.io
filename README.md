## 🎯 Назначение и функционал платформы

Веб-портал разработан в методологической концепции **«Dry Lab»** (компьютерный лабораторно-семинарский практикум) и объединяет:

1. **Каталог всех 18 семинарских и практических занятий курса** (36 академических часов, 12 работ Dry Lab) с дидактическими целями, используемым ПО (ComBase Predictor, цифровой микроскоп, калькуляторы Бигелоу), стандартами ГОСТ / регламентами ТР ТС и формами отчетности.
2. **Интерактивный цифровой справочник Семинара 1** («Физико-химические основы микробного гомеостаза и методы регулирования пищевых сред»):
   - Полнотекстовая теория с 13 оригинальными научными иллюстрациями.
   - Справочные таблицы пороговых значений $a_w$, констант слабых кислот ($pK_a$, $S_0$) и допустимых дозировок ТР ТС 029/2012.
   - **4 интерактивных инженерных калькулятора**:
     - Конвертер $pH \leftrightarrow pOH \leftrightarrow [H^+] \leftrightarrow [OH^-]$ с санитарным вердиктом;
     - Ионная сила $I$ и коэффициент активности $\gamma$ по теории Дебая-Хюккеля;
     - Доля активной недиссоциированной формы $HA$ по Гендерсону-Хассельбаху;
     - Растворимость кислот и контроль выпадения осадка ($pH_{\text{крит}}$).
   - **4 подробных пошаговых разобранных примера типовых задач** с выводами для инженеров по качеству.
   - Скачивание официального печатного буклета студента (`student_handout.pdf`).
3. **Модуль 15-минутного экспресс-контроля знаний**:
   - Форма регистрации студента (Фамилия, Имя, Учебная группа, Направление подготовки).
   - Генерация индивидуального билета из **4 случайных задач** (по 1 из каждого ключевого раздела).
   - Фиксированный таймер обратного отсчета на **15:00 минут** с цветовой индикацией ($\le 3$ мин — желтый, $\le 1$ мин — пульсирующий красный) и автоотправкой при истечении времени.
   - Ввод числовых ответов с проверкой точности и полями для обоснования.
   - **Синхронизация с Google Drive преподавателя** (Google Sheets) через Google Apps Script Web App.
   - Резервное сохранение в `localStorage` браузера и генерация уникальной электронной квитанции (`RUDN-MB-XXXX-YYYY`) с возможностью скачивания TXT-файла.

## 🚀 Настройка синхронизации с Google Drive (Google Sheets)

1. Откройте [Google Таблицы](https://sheets.google.com) и создайте новую таблицу (например, `Результаты_Микробиология_Семинар_1`).
2. В меню таблицы выберите **Расширения → Apps Script**.
3. Скопируйте код из файла [`google-apps-script/Code.gs`](google-apps-script/Code.gs) и вставьте в редактор скрипта.
4. Нажмите **Развернуть → Новое развертывание**, выберите тип **Веб-приложение**:
   - *Запуск от имени:* **Я**
   - *У кого есть доступ:* **Все (даже без аккаунта Google)**.
5. Скопируйте полученный **URL веб-приложения** и вставьте его в [`js/config.js`](js/config.js) в параметр `GOOGLE_SCRIPT_URL`.

Подробная иллюстрированная инструкция находится в [`google-apps-script/README.md`](google-apps-script/README.md).

## 🌐 Развертывание на GitHub Pages

Репозиторий настроен для автоматической публикации на GitHub Pages:
1. Перейдите в **Settings → Pages** репозитория на GitHub.
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите ветку `main` и корневую папку `/ (root)`.
4. Нажмите **Save**. Сайт будет доступен по адресу:  
   `https://yaroslavtsevam.github.io/microbio-ati-rudn.github.io/`
